# 市场参与者图鉴

20 类市场参与者（一级市场、交易所与二级市场、场外与批发、大宗商品、基础设施与政策）的工作方式、交易过程泳道图，以及撮合、集合竞价、做市、招标、价格评估窗口等可操作示意。规则资料核对至 2026-11-04，示例数字均为虚构。不构成投资建议。

纯静态页面，无构建步骤：`index.html` 包含全部内容和脚本。

## 在 iPhone 上使用
用 Safari 打开网址 → 分享 → 添加到主屏幕。打开过一次后可以离线阅读（`sw.js` 缓存页面和用到的字体分块）。
